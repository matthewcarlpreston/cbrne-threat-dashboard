Scope guardrail: this dashboard aggregates and classifies publicly reported news coverage of CBRN-E and novel-weapons events — proliferation, seizures, incidents, policy actions, sanctions. It does not collect, generate, or reference any technical weapons information (synthesis routes, device design, targeting data, etc.). It is an OSINT signal-detection tool, not a weapons reference. See README for methodology.
